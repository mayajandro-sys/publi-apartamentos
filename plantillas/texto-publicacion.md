# Plantilla · Texto de publicación

1. **Gancho (primera línea):** una frase que haga parar el dedo.
   _Ejemplo: "El mejor atardecer de [destino] se ve desde esta terraza 🌅"_
2. **Desarrollo (2 o 3 líneas):** qué se ve, qué se siente, un detalle útil.
3. **Llamada a la acción:** "Guárdalo para tu próxima escapada", "Escríbenos para ver fechas".
4. **Hashtags:** 3 a 5 (destino, tipo de viaje, zona).
