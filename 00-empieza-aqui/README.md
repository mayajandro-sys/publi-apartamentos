# 00 · Empieza aquí

1. Lee el [glosario](glosario.md) una vez. No hace falta memorizarlo, vuelve a él cuando no entiendas una palabra.

Si haces algo dos veces, conviértelo en un SOP o en una plantilla y guárdalo aquí. Así el proyecto crece sin que tengas que recordarlo todo.
